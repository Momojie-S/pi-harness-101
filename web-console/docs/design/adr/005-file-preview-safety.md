# ADR-005: 文件预览的安全与健壮性策略

## 状态

Accepted

## 背景

文件查看器用 `fs.readFile` 读工作目录内任意文件。若不限制：

- 二进制文件（图片/exe/zip/...）按 utf8 解码 → 乱码
- 超大文件 → 全量读入内存，卡顿/撑爆
- 未知二进制（无标准扩展名）→ 仍乱码

## 决策

三层过滤，命中则显示"不支持预览"提示（不乱码、不卡）：

1. **扩展名黑名单**：已知二进制类型（png/jpg/exe/zip/pdf/docx/...）直接拒绝（不读内容，快）
2. **大小限制**：超过 1MB 拒绝
3. **NUL 字节检测**：读取 buffer 检查是否含 `\0`（二进制标志），命中拒绝

svg/pem/crt 等文本格式不列入黑名单。

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| 无限制 | 简单 | 二进制乱码、大文件卡 |
| 仅扩展名黑名单 | 快 | 未知二进制漏网 |
| 仅内容检测 | 通用 | 大文件仍全读 |
| 三层过滤（本决策） | 全面 | 实现稍复杂 |

## 后果

### 正面

- 二进制/大文件优雅拒绝，不乱码不卡
- 扩展名快速判断（不读内容）

### 负面

- 黑名单需维护（新二进制类型要加）
